# UI/UX Context

- Design for small-business operators and real workflows, not component showcases.
- Primary workflows: fast order creation, status updates, customer lookup, product selection, tracking-link sharing.
- Human-designed hierarchy: deliberate typography, spacing, alignment, restrained color, useful density, clear affordances.
- Avoid generic AI-dashboard aesthetics, decorative gradients/glows/blobs, excessive cards/pills/shadows, fake analytics, and gratuitous animation.
- Reuse common primitives but allow page-specific composition when it improves information architecture.
- Every important interaction has applicable loading/success/error/empty/unauthorized/not-found/disabled states and prevents duplicate submissions.
- Use semantic HTML, keyboard access, visible focus, labels, contrast, accessible names, restrained ARIA, and reduced-motion considerations.
- Mobile is first-class, especially tracking, order creation, status updates, lookup, selection, and sharing.
