**Owner decisions that resolved the AMB-002 blockers (2026-10-18, now DEC-013):**

- **Cancellation matrix:** `CANCELLED` is reachable from every pre-delivery status (`PENDING`, `CONFIRMED`, `PREPARING`, `READY`, `OUT_FOR_DELIVERY`) and never from `DELIVERED`.
- **Forward-transition strictness:** exactly one step forward along `PENDING → CONFIRMED → PREPARING → READY → OUT_FOR_DELIVERY → DELIVERED` — no skipping, no going backwards (the spec's `DELIVERED → PREPARING` example is therefore forbidden).
- **Cancellation note:** optional free text; a reason is not required.
- **Who may cancel:** both OWNER and STAFF, subject to the existing tenant-membership and authorization checks.

Out of scope for M6 (do not resolve here): DEC-002/003/004/005, F4, §36 seed data, the public tracking page and copy/share (M7), dashboard counts / search / filter / pagination (M8).
